# Pixie
An user interface app for our robot pet companion Pixie.

## Environment

Create a `.env` file from `.env.example` and set your Google Gemini API key before running the app.

```env
GEMINI_API_KEY=YOUR_GOOGLE_API_KEY_HERE
GEMINI_MODEL=gemini-2.5-flash
GEMINI_FALLBACK_MODEL=gemini-2.5-pro
```

Do not commit your real API key into the repository.
